# 轻语 · 英文润色

Mac WhatsApp 输入完英文，点击草稿旁的磨砂小按钮，在字典样式的气泡浮层中查看两条英文候选：第一条是带常用缩写的自然口语，第二条是正式书面语。点选一条替换，由你发送。

0.3：按钮从 32 点缩小到 26 点并移到输入框外侧。候选气泡优先向下展开；输入框靠近屏幕底部、下方空间不足时自动向上。右上角图钉可固定，固定后点击别处或切回 WhatsApp 不会收起。未固定时，点外面或按 Esc 收起并取消在途请求。正常候选只显示英文，有歧义时附一行中文帮助选择。右键候选可复制。旧候选替换前仍核对原草稿，避免覆盖变化后的内容。App 包含独立的轻语图标。

设置分为“常规、AI 服务、历史、权限”四页。常规页可开启 macOS 原生登录项，并选择是否保存历史；历史默认最多保留 50 条，可在 10–200 条之间调整。历史包含原文、两条候选和生成时间，只写入本机 Application Support，文件权限为当前用户读写。AI 服务页可自定义两条候选的风格提示词并一键恢复默认值。权限页显示当前辅助功能授权状态。

## 首次使用

1. 打开 `轻语.app`，菜单栏会出现 ✨。
2. 在“设置…”中填写 AI 服务地址、该服务支持的模型名称和 API 密钥，也可以修改两条候选的风格提示词。点击保存。支持 HTTPS Chat Completions API 的 JSON 模式。密钥存入 macOS 钥匙串，按服务地址分别保存。
3. 点击“打开辅助功能设置”，在 macOS 系统设置中允许“轻语”。必须由你完成授权。
4. 回到 WhatsApp 的聊天输入框，写完英文，点击浮动 ✨。
5. 点击你要采用的英文候选即可替换；如果有歧义，先看候选下的中文意思。最后自行发送。

也可从菜单栏选择“打开润色窗口”，粘贴英文，生成后复制使用。AI 设置不预填模型，须使用你的服务账户实际支持的模型。

## 行为边界

- 只定位 `net.whatsapp.WhatsApp` 中的 `ChatBar_ComposerTextView`，不遍历消息历史和联系人列表。按钮优先跟随末尾字符；无法获得字符位置时，显示在输入框右上沿。
- 点击“润色”才将当前草稿发送到设置的服务。ChatGPT 对话不会自动成为这个应用的 AI 服务。开启历史时，原文和两条候选只保存在本机；应用不记录密钥或额外草稿日志。
- 保存设置只验证格式；实际连通性在第一次润色时确认。需要有效密钥、模型权限和服务额度。
- AI 可能误解原意，请核对中文意思、人名、数字；歧义检测不是保证。
- 离开预览窗口或锁屏后，旧结果的直接替换会停用；回到 WhatsApp 可重新点击 ✨ 获取当前草稿。
- 替换前再次核对窗口、输入框、聊天标题及原文。原文或聊天改变时停止替换。辅助功能写入不受支持时提供复制，不使用模拟键盘或自动发送。
- 生成中可取消；关闭预览也取消请求并丢弃迟到结果。
- 屏幕睡眠、锁屏或用户会话离开时暂停定位。没有截图或输入监控权限需求。
- 此本机版本使用固定的指定要求 `com.xy.english-polish`。从旧身份升级后需要重新允许一次辅助功能，之后覆盖更新沿用同一身份。

## 开发

Apple silicon Mac，macOS 13+，Xcode 命令行工具，Python 3。

```sh
python3 build.py --test
python3 build.py
```

构建使用本机临时签名，并嵌入固定的应用身份规则。首次安装或从旧构建升级时需要重新允许一次辅助功能，后续构建沿用同一身份规则；构建不创建证书，也不修改钥匙串信任。

构建产物：`build/轻语.app`。安装到 `~/Applications` 后再授予权限，避免授权给构建目录副本。

API 请求格式参考 [OpenAI Chat Completions 官方文档](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)。
